Instruct an LLM on writing as precisely as you already instruct it on code. Pick one value from each axis - Voice, Tone, Style, Format - and the `writing-instruction-builder` skill assembles a prompt prefix that steers any LLM toward a precise register, reasoning pattern, and layout. Swap one value and the writing changes in a way you can point at.

The catalog holds 121 entries. The 98 that ship in the plugin (16 Voice, 15 Tone, 15 Style, 52 Format) carry `machine-verified`: each passes every automated check and has not yet been read line by line by the maintainer. The other 23 are drafts, still under review: 20 format candidates and one new entry each on Voice, Tone, and Style. Every shipped entry has worked examples across twelve anchor topics, and the catalog adds side-by-side diff-pairs that isolate a single axis, recipes that bundle common combinations, and copyable format templates.

:::note[Does it actually work?]
Blind judges attributed near-neighbour samples to the right entry 8 of 8 times with a same-family judge and 18 of 18 times with a judge from another vendor. They also rejected 3 of 3 deliberate caricatures. These are small tests, and the [evidence page](concepts/adherence-evidence/) states every limit.
:::

## The four axes

Voice is who is speaking (persistent identity). Tone is how they sound right now (situational register). Style is how the reasoning is structured, Format is the container it arrives in. All four are independent, and any value from any axis composes with any other. Voice and Tone are the most confusable pair, so the rule is: voice is what does not change, tone is what changes per piece.

| Axis | What it controls | Example entries |
|------|------------------|-----------------|
| **Voice** | Persistent writer identity: worldview, characteristic concerns, professional archetype | [pragmatic-architect](reference/voices/pragmatic-architect/), [pastoral](reference/voices/pastoral/), [journalist](reference/voices/journalist/), [coach](reference/voices/coach/) |
| **Tone** | Situational register layered on top of voice | [candid](reference/tones/candid/), [warm](reference/tones/warm/), [reverent](reference/tones/reverent/), [urgent](reference/tones/urgent/) |
| **Style** | Cognitive and rhetorical pattern: how ideas are sequenced | [problem-solution](reference/styles/problem-solution/), [layered-disclosure](reference/styles/layered-disclosure/), [socratic-inquiry](reference/styles/socratic-inquiry/), [dialectic](reference/styles/dialectic/) |
| **Format** | Visual and structural container: headings, sections, layout | [adr](reference/formats/adr/), [daily-standup](reference/formats/daily-standup/), [slack-message](reference/formats/slack-message/), [devotional-entry](reference/formats/devotional-entry/) |

## Quick start

The library is packaged as a Claude Code plugin, published in the Product on Purpose marketplace. Install it from inside Claude Code:

```
/plugin marketplace add product-on-purpose/agent-plugins
/plugin install writing-style-catalog@product-on-purpose
```

Already installed? Run `/plugin update writing-style-catalog`. For the direct-from-repo and Claude.ai / Claude Desktop paths, see the [installation guide](guides/install/).

Then compose an instruction from any combination of axes:

```
/writing-style-catalog:writing-instruction-builder voice=pragmatic-architect tone=candid style=problem-solution format=adr
```

The skill outputs a structured prompt prefix. Copy it into your system prompt or prepend it to your writing task.

Not sure which combination fits? Describe the situation instead and let [entry-recommender](guides/recommend-entries/) pick it for you, composing the prompt in the same step.
